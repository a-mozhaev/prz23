# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- Сложение, вычитание, умножение, деление, возведение в степень
- Обработка ошибок ввода
- Обработка деления на ноль
- Обработка возведения нуля в отрицательную степень

## ▫ Алгоритм работы
 
Ниже представлена блок-схема основной логики калькулятора:

```mermaid 
 graph TD
     A[Старт] --> B[Ввод первого числа]
     B --> D[Ввод операции +, -, *, /, **, sqrt]

     D --> E{Операция sqrt?}
     E -- Да --> F{Число1 < 0?}
     F -- Да --> G[Вывод: Ошибка извлечения корня из отр. числа]
     F -- Нет --> H[Вычисление: корень числа1]

     E -- Нет --> I[Ввод второго числа]
     I --> J{Операция / и число2 == 0?}
     J -- Да --> K[Вывод: Ошибка деления на 0]
     J -- Нет --> L{Операция ** и число1 == 0 и число2 < 0?}
     L -- Да --> M[Вывод: Ошибка возведения 0 в отр. степень]
     L -- Нет --> N[Вычисление бинарного результата]

     H --> O[Вывод результата]
     N --> O

     G --> P[Конец]
     K --> P
     M --> P
     O --> P
```

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск
1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
python3 -m venv venv
3. Активируйте окружение:
source venv/bin/activate
4. Запустите программу:
python main.py
