# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- Сложение, вычитание, умножение, деление, возведение в степень
- Обработка ошибок ввода
- Обработка деления на ноль
- Обработка возведения нуля в отрицательную степень
- Хранение истории вычислений в БД и поиск по ней
- Статистика вычисений (кол-во, среднее, наибольшее и наименьшие значения)


## ▫ Алгоритм работы

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
flowchart TD
    A([Старт]) --> B["Инициализация БД: init_db()"]
    B --> C{"Выбор действия в меню"}

    C -- "1. Вычисление" --> D["Ввод первого числа с проверкой"]
    D --> E["Выбор операции: +, -, *, /, **, sqrt"]

    E --> F{"Операция sqrt?"}

    F -- Да --> G{"Число 1 < 0?"}
    G -- Да --> H["Ошибка извлечения корня"]
    G -- Нет --> I["Вычисление квадратного корня"]

    F -- Нет --> J{"Операция допустима?"}
    J -- Нет --> K["Ошибка: неизвестная операция"]
    J -- Да --> L["Ввод второго числа с проверкой"]

    L --> M{"Деление на ноль?"}
    M -- Да --> N["Ошибка деления на ноль"]
    M -- Нет --> O{"Ноль в отрицательной степени?"}

    O -- Да --> P["Ошибка возведения в степень"]
    O -- Нет --> Q["Выполнение арифметической операции"]

    I --> R["Вывод результата"]
    Q --> R

    R --> S["Сохранение в SQLite: save_record()"]
    S --> C

    H --> C
    K --> C
    N --> C
    P --> C

    C -- "2. История" --> T["Получение последних 10 записей: get_history()"]
    T --> U["Вывод истории"]
    U --> C

    C -- "3. Очистка" --> V["Удаление записей: clear_history()"]
    V --> C

    C -- "4. Статистика" --> W["Получение статистики: get_statistics()"]
    W --> X["Вывод количества, среднего, максимума и минимума"]
    X --> C

    C -- "5. Поиск" --> Y["Ввод ключевого слова"]
    Y --> Z["Поиск записей: search_history()"]
    Z --> AA["Вывод результатов поиска"]
    AA --> C

    C -- "0. Выход" --> AB([Конец])
    C -- "Неверный выбор" --> AC["Сообщение об ошибке"]
    AC --> C
```


## Алгоритм работы БД

Ниже представлена блок схема работы БД:

```mermaid
flowchart TD
    A[Запуск калькулятора] --> B[init_db: Инициализация БД]
    B --> DB[(SQLite: history.db)]
    B --> C{Выбор действия в меню}

    C -- 1. Вычисление --> D[Выполнение вычисления]
    D --> E[save_record]
    E -- INSERT --> DB

    C -- 2. История --> F[get_history]
    F <-- SELECT --> DB
    F --> G[Вывод последних 10 записей]

    C -- 3. Очистка --> H[clear_history]
    H -- DELETE --> DB

    C -- 4. Статистика --> I[get_statistics]
    I <-- COUNT, AVG, MAX, MIN --> DB
    I --> J[Вывод статистики]

    C -- 5. Поиск --> K[search_history]
    K <-- SELECT LIKE --> DB
    K --> L[Вывод найденных записей]

    C -- 0. Выход --> M[Завершение программы]
```

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск
1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
python3 -m venv venv
3. Активируйте окружение:
source venv/bin/activate
4. Запустите программу:
python main.py
